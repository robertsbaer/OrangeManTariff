# Amazon Tariff Surcharge Chrome Extension

This extension displays the tariff surcharge next to the total amount on Amazon product pages for items shipped from China, according to current US tariff rules.

## Usage

1. Load the extension in Chrome:
   - Go to chrome://extensions
   - Enable "Developer mode"
   - Click "Load unpacked" and select this folder

2. Visit an Amazon product page. If the product is shipped from China and matches a tariffed category, the surcharge will appear next to the price.
